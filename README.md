# Python Functions: Welcome & Toolbox

`welcome.py` contains a `welcome()` function that returns personalized PLP greeting messages.

`toolbox.py` contains three functions: `double()`, `is_pass()`, and `greet()`.

The `greet()` function was the hardest to write because it uses an optional parameter with a default value. I had to make sure it used `"Hello"` when no greeting was provided and used the given greeting when one was provided.
